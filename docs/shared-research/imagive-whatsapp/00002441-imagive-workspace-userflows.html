Reading this flow: the amber diamonds are the only three moments where permission decides what happens next — joining requires a valid invite, adding a brand requires Admin/Manager, and Organization Settings is Admin-only. Everything else (switching org, switching brand, using the product) is open to any member.
Who this is for: the Organization Admin — the only role that can create an organization, and the only one who configures members, brands, permissions and billing for everyone else. Creating an org always needs a reserved Organization ID issued by Imagive; it's never self-serve.

Reading this flow: the only hard gate is the Organization ID — an admin can't create an org without one, and it can't be typed freely, it has to be pre-reserved by Imagive. Everything under Organization Settings (profile, members, brands, permissions, billing) is this admin's own control surface, invisible to every other role.

How to read each mock

Every ad is built from stacked zones — one element per zone, pin at the zone's right edge. No pin ever sits on the content. Match the pin number to the key beside the mock. The LLM spec line is a compact JSON of the format's structure — feed these 40 specs to a model and it learns the layout grammar of DTC statics. Product emojis are placeholders for real product photography.

AdBrain · the brain

How AdBrain decides what to ship, kill and scale

Raw Meta numbers go in one end; a ranked list of honest moves comes out the other. In between, a fixed chain of rules does the thinking — and no number is ever shown unless a stated rule produced it.

Every stage is plain, deterministic code (no AI guessing the numbers). "Not enough data" is a real answer the engine is allowed to give, at every step.

J1→ J2→ J3/J4→ J6→ J10→ objective decision→ rubric
J1

The spend floor

lib/rules/spend-floor.ts

Before anything is judged, an ad must have spent above a small floor (₹300 / $5) in the last 7 days. Below that it is held as "keep testing", re‑checked daily — never scored, never deleted.

Honest rule

No verdict on an ad that never got enough budget to prove itself.

J2

Compare like with like

lib/rules/comparator.ts

An ad is only ever measured against other ads with the same objective, weighted toward your own long history. A sales ad is never graded against a traffic ad.

Honest rule

No borrowed public benchmarks, no cross‑objective comparisons.

J3·J4

The causality ladder

lib/causality.ts

When a number drops, the cause is diagnosed in a fixed order: measurement first, then tracking, auction/CPM, landing page, stock, audience saturation, too‑many‑edits — and creative fatigue last.

Honest rule

A broken pixel or a costlier auction is not a bad creative. Never blame the ad until every cheaper cause is ruled out.

J6

Trust gates

lib/rules/trust-gates.ts

Concrete "not worthy until" thresholds. A winner needs at least ~100 purchases and 3 days of delivery. "8× ROAS on 2 sales" is a coin toss, so the gate blocks it whatever the headline says.

Honest rule

A small sample never earns a big claim. Missing data is dropped, never filled with an average.

J10

The verdict

lib/rules/verdict.ts

A CreativeScore blends performance, day‑wise trend, freshness and funnel health, then lands one call. A kill only after the causality ladder has cleared every non‑creative cause.

SCALE REFRESH HOLD / WATCH KILL
Honest rule

Never kill on a symptom. When in doubt, "do not kill yet".

DEC

Objective‑aware decision

lib/scoring/decision.ts

Not every ad is about sales. Traffic, engagement and awareness ads are read on their own metric (CTR, reach) plus day‑wise fatigue — giving real Scale / Continue / Refresh / Pause / Hold calls instead of one blanket ROAS. Confidence rises as more days of data arrive.

Honest rule

Judge each ad on the job it was set to do, not on a metric it was never optimised for.

RUB

The rubric registry

lib/scoring/rubrics.ts

Every score on screen carries its rubric — the question it answers, the formula, the real inputs, the benchmark. The compute path and the "Why this score?" panel read the same source, so a number and its explanation can never drift apart.

Honest rule

If it is on the screen, you can open the exact reason it says what it says.

Two guards running the whole way through

Confidence framework

lib/confidence.ts

Every recommendation carries a confidence built from data completeness, sample size and signal agreement — and hard caps stop a pretty blend from outranking a thin or confounded read. It rises as you connect GA4 and Shopify.

The honesty validator

lib/validator.ts

Plain code (no AI) checks the written summary before it reaches you: every money figure must match a real computed number, every claim must cite real evidence. If not, it is held back, not shown.

The one law behind all of it: insufficient data is a state, not a guess. The engine would rather tell you "not enough data yet" than show you a confident wrong number.

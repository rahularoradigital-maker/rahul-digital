# AdBrain — Product Naming Options

Positioning to name for: an AI strategist beside the media buyer — decisive ("the verdict in one
sentence"), trustworthy (show-the-working), for DTC/agency ad teams. Names must NOT read as
"another reporting/metrics dashboard" (the category we position against). Availability notes are
from a quick web check (2026-08-25) and MUST be verified with a registrar + USPTO before adopting.

## Flags on the in-play names
- **AdBrain** (current placeholder): "AdBrain" was a real cross-device adtech company (acquired by
  Nielsen/Gracenote). Adtech trademark history → **not a safe long-term name.**
- **Metris** (the design-zip name): no ad-analytics collision found, but it reads as "metrics" —
  the exact reporting category we position AGAINST. The name works against the pitch.

## Five options

### 1. Verdikt  (recommended)
- **Rationale:** the product literally leads with "the verdict, in one sentence." Verdikt = a
  decisive call, not a report. Nails the "decide, don't just measure" positioning.
- **Brand fit:** anchors the whole decision-first architecture (Observation→...→Action ends in a verdict).
- **Memorability:** short, punchy, the "k" spelling is distinctive and ownable.
- **Domain/TM:** a marketing-adjacent agency uses "Verdikt" → medium risk; verify. verdikt.com likely
  taken (try verdikt.ai / getverdikt.com). Distinctive spelling helps registrability.

### 2. Nextdollar  (recommended, strongest positioning fit)
- **Rationale:** the product answers "where should the next dollar go?" — the media buyer's actual
  question. Descriptive of the core value without being a metrics word.
- **Brand fit:** ties directly to the budget/scaling + marginal-ROAS engine ("next +$10K → est. ROAS").
- **Memorability:** a concrete phrase buyers already say; easy to spell/pronounce.
- **Domain/TM:** compound term, low collision likelihood; nextdollar.ai / trynextdollar.com. Verify.

### 3. Nextmove
- **Rationale:** "what's the next move?" = the product's one-line job. Decisive, action-framed.
- **Brand fit:** matches the "do this today" action center.
- **Memorability:** very easy; common phrase.
- **Domain/TM:** common term → harder TM/exact-match domain; likely needs a modifier (nextmove.ai).
  Medium-high collision; verify carefully.

### 4. Cadant
- **Rationale:** evokes cadence (the test→learn→scale rhythm, a core concept) + candor (show-the-
  working). Abstract-brandable, not a metrics word.
- **Brand fit:** supports the creative-velocity + honesty pillars.
- **Memorability:** clean two-syllable, ownable; no current meaning to fight.
- **Domain/TM:** prior "Cadant" was a defunct 2002 cable-modem company (different category, dormant)
  → likely registrable; verify cadant.com/.ai.

### 5. Metris  (in-play; keep only if you accept the caveat)
- **Rationale:** measure/"metris" (Greek, measure); short, abstract, brandable.
- **Brand fit:** WEAK — leans toward "metrics," the reporting category we explicitly reject.
- **Memorability:** decent, but easily confused with "metrics"/"Ace Metrix"/"AdMetrics".
- **Domain/TM:** used elsewhere (e.g. metrology); no ad-analytics collision found; verify.

## Recommendation
Lead with **Verdikt** (best concept fit) or **Nextdollar** (best positioning fit, likely most
available). Both say "decision, not dashboard" — the whole point. Retire **AdBrain** (adtech TM
history) as anything but a working placeholder. Treat **Metris** cautiously: it fights the pitch.
Next step before committing: registrar check (.com/.ai) + a USPTO search in class 42 (SaaS) /
class 35 (advertising) for the top two.
